2. 變換拆解

依「先伸縮，再平移」逐步看

基本圖形 y = f(x)

先熟悉 y=sin x、y=cos x 或 y=tan x 的原始形狀，再逐步加入參數。

讀圖口訣：
A 看「高矮」；B 看「疏密」；h 看「左右」；D 看「上下」。
對 sin、cos 而言，週期是 2π / |B|；對 tan 而言，週期是 π / |B|。

單位圓上的點 P(cos θ, sin θ)：cos θ 是 x 座標，sin θ 是 y 座標。把 y 座標隨 θ 的變化依序記錄，就會得到正弦曲線。

橘色切線示意 tan θ。當 cos θ 接近 0 時，tan θ 的絕對值會快速增大，這正對應正切圖形的垂直漸近線。

6. 教學提示

可投影示範，也可讓學生自行探索

建議流程 A：先觀察再公式化

  1. 固定 B=h=D，先只改 A，讓學生說出「高度」怎麼變。
  2. 固定 A=h=D，改 B，觀察波形疏密與週期。
  3. 再加入 h、D，要求學生用「左／右、上／下」描述。
  4. 最後才整理成振幅、週期、平移的公式。

建議流程 B：單位圓 → 曲線

  1. 用特殊角按鈕切換 0、π/6、π/4、π/3、π/2。
  2. 要求學生先預測 sin、cos 正負，再看數值。
  3. 把 θ 慢慢播放一圈，連結「圓周運動」與「週期函數」。
  4. 切到 tan，特別觀察 cos θ 接近 0 時的變化。
