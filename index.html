1. 圖形實驗室

先動手，再看規律
選擇基本函數
y = sin x本頁用：y = A·f(Bx - h) + D
可用滑桿，也可以直接在右側輸入數值；輸入框不受滑桿範圍限制。pi = π，例如可輸入 pi/2、-pi/3、8*pi。
建議照順序操作：①左右平移 → ②左右伸縮 → ③上下伸縮 → ④上下平移。滑桿方便觀察；輸入框可輸入更大的數值，不受滑桿範圍限制。輸入 pi 就代表 π。
目前函數 基本函數 y=f(x) 中心線 / 漸近線

2. 變換拆解

照順序按按看：左右平移 → 左右伸縮 → 上下伸縮 → 上下平移

基本圖形 y = f(x)

先熟悉 y=sin x、y=cos x 或 y=tan x 的原始形狀，再逐步加入參數。

操作順序：
h 看「左右平移」→ B 看「左右伸縮」→ A 看「上下伸縮」→ D 看「上下平移」。
例如 y = sin(2x - π)：先右移 π，再左右壓縮成原來的 1/2。
對 sin、cos 而言，週期是 2π / |B|；對 tan 而言，週期是 π / |B|。

3. 單位圓與圖形連動

x 座標1

單位圓上的點 P(cos θ, sin θ)：cos θ 是 x 座標，sin θ 是 y 座標。把 y 座標隨 θ 的變化依序記錄，就會得到正弦曲線。

橘色切線示意 tan θ。當 cos θ 接近 0 時，tan θ 的絕對值會快速增大，這正對應正切圖形的垂直漸近線。
